# Screen Sketch S Pen v1.2

Galaxy Tab + S Pen용 화면 오버레이 드로잉 앱 프로토타입입니다.

## 핵심 기능
- DRAW ON / TOUCH ON 즉시 전환
- 펜, 형광펜, 지우개
- S Pen 측면 버튼 임시 지우개
- 12색 팔레트
- 직선, 화살표, 사각형, 타원
- 즐겨찾기 펜 프리셋
- 굵기 / 투명도 / 스무딩
- Undo / Redo / 전체 삭제
- 주석 표시/숨김
- 접이식 플로팅 툴바

## APK 자동 빌드
`.github/workflows/build-apk.yml`에 GitHub Actions 빌드가 포함되어 있습니다.
자세한 순서는 `BUILD_IN_GITHUB.md`를 보세요.
