# Screen Sketch S Pen v1.4

## 핵심 수정

- PEN ON/OFF와 앱 종료를 완전히 분리했습니다.
- PEN OFF는 전체 화면 드로잉 입력만 비활성화합니다.
- 툴바와 기존 그림은 계속 화면에 남습니다.
- 앱 완전 종료는 빨간 `EXIT APP`을 두 번 눌렀을 때만 수행합니다.
- 알림에서도 `펜 ON/OFF`와 `앱 완전 종료`를 별도 제공하도록 변경했습니다.
- 서비스는 `START_STICKY` + `stopWithTask=false`로 동작해 런처 화면을 닫거나 최근 앱에서 치워도 툴바가 유지되도록 했습니다.
- Android가 서비스를 재시작하거나 앱 프로세스가 다시 만들어져도 마지막 그림을 내부 저장소에서 자동 복원합니다.

## 자동 저장/복원

- 자유선/도형 그리기 완료 시 자동 저장
- 지우개 작업 완료 시 자동 저장
- Undo/Redo/Clear 시 자동 저장
- 펜 색상, 굵기, 투명도, 현재 도구, 툴바 위치, 접힘 상태, PEN ON/OFF 상태 기억

## 안전/편의 기능

- 툴바는 항상 별도 최상단 오버레이로 유지
- PEN OFF에서는 입력 레이어만 `NOT_TOUCHABLE`로 전환
- 투명 오버레이 합성 불투명도를 Android 12+ 터치 통과 제한에 맞게 낮춤
- CLEAR 2회 확인
- EXIT APP 2회 확인
- 툴바 드래그 후 좌/우 가장자리 자동 스냅
- PNG/PDF/PRINT 기능 유지
- S Pen 버튼 순간 지우개 유지
